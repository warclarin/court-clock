# Court Clock

A basketball game clock and shot clock for Android. Run the scorer's table from one phone: game clock, shot clock, score and timeouts. No internet needed.

## Download

**[Download Court Clock for Android](https://github.com/warclarin/court-clock/releases/latest/download/court-clock.apk)**

This link always gets the newest version. It needs Android 13 or newer. There is no iPhone version yet.

## Install

1. Open the download link on your Android phone. The file `court-clock.apk` downloads.
2. Open the downloaded file.
3. If Android says your browser isn't allowed to install apps, tap **Settings**, turn on **Allow from this source**, then go back and tap **Install**.
4. If Google Play Protect warns you about the app, choose to install it anyway. The app isn't on the Play Store, so Android doesn't recognise it.

## Update

Download from the same link and install it over the old version. Your settings and team names are kept.

## Three ways to use it

- **Both clocks:** one phone runs the game clock, shot clock, score and timeouts.
- **Game clock:** the game clock, score and timeouts.
- **Shot clock:** only the shot clock, for a second phone.

## Features

- **24 and 14 second resets.** After a made basket, tap 24 and the shot clock waits at 24 while the game clock keeps running. Tap **Go** when the inbound is touched.
- **Buzzer sound and vibration** when the game clock or shot clock runs out.
- **Timeouts** with a countdown.
- **Your rules:** halves or quarters, period and overtime length, shot clock length, and timeouts per half.
- **League and team names** on the scoreboard.
- **Portrait or landscape.**
- **The game is saved** as you go, so closing the app doesn't lose it.
- **The screen stays on** during a game.
